# EduPredict Real
Dữ liệu thật: Cortez, P. (2008). Student Performance. UCI. https://doi.org/10.24432/C5TG7T
Ứng dụng tự tải ZIP UCI hoặc đọc student-mat.csv đặt cạnh app.py. Nếu không tải được, tải CSV thủ công từ https://archive.ics.uci.edu/dataset/320/student+performance . Không sinh dữ liệu mô phỏng.
Chạy: py -3.12 -m pip install -r requirements.txt
Sau đó: py -3.12 -m streamlit run app.py
Deploy: upload app.py, requirements.txt, README.md và student-mat.csv nếu có lên GitHub; chọn main và app.py trên Streamlit Cloud.
G3 là điểm cuối năm môn Toán ở Bồ Đào Nha, không phải điểm thi riêng biệt tại Việt Nam. Lịch sử riêng theo phiên, không lưu lâu dài.
